# Inspiration sources for Ty LuWa

Rendered from BookCompiler `knowledge/directories/design-inspiration-sources.yaml`
v1.0.0 (verified 2026-09-06). Consultation directory, not principles: these calibrate
the eye and supply comparative evidence before design work.

## Rules of use

- Pull ~3 comparable references **before** designing and name the mechanism that
  makes each work — never borrow by adjective [CP-020].
- References inform; the merkwetten in `CLAUDE.md` and `assets/brand/` decide
  [CP-031]. The brand names its own UX references too (see CLAUDE.md): the calm of
  Airbnb, the clarity of Booking **without** its dark patterns, the holiday feel of
  good hotel sites — use those with the same mechanism discipline.
- Steal mechanisms, never surfaces. Novelty checks against convention before
  adoption [CP-031, CP-032] — a guest should never have to learn this site.

## Primary for this repo

**[Refero](https://refero.design/)** — real app screens organized by page type and
flow (profile from reputation; site is script-only to fetchers).
*Reach for it when:* designing the availability/request flow — how real products
treat date input, request confirmation, waiting states.

**[Nicely Done](https://nicelydone.club/)** — 201,800+ real product screens with
text-in-screenshot search (free tier).
*Reach for it when:* needing several real examples of one pattern fast: forms,
confirmations, empty states, galleries.

**[Screensdesign](https://screensdesign.com/)** — iOS teardowns of onboarding and
conversion mechanics.
*Reach for it when:* tuning the mobile experience — guests plan holidays on phones;
the sticky CTA and thumb-reach patterns live here. Take the mechanics, leave the
paywall aggression.

**[Httpster](https://httpster.net/)** — 3,116 hand-picked sites, browsable by style;
strong on warm, typographic, calm work.
*Reach for it when:* art-directing the holiday feel — warmth without kitsch,
matching the marine/zand/salie world.

**[One Page Love](https://onepagelove.com/)** — 9,116 one-pagers plus 8,976 section
examples; genres include personal and service.
*Reach for it when:* composing page narrative order or a single section (hero,
photo mosaic, FAQ, contact).
